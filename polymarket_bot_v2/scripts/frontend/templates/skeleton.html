8 · Semantic Surface Panels v-surface-*
v-surface-info — Use for neutral informational notices, policy hints, and general guidance blocks. Background rgba(58,191,248,0.09) · border rgba(58,191,248,0.25) · color #bae6fd
v-surface-success — Use for confirmed positive states: MFA enabled, wallet bound, deposit confirmed. Background rgba(16,185,129,0.10) · border rgba(16,185,129,0.25) · color #86efac
v-surface-warning — Use for cautionary notices: MFA disabled, unbound wallet, withdrawal fee alerts. Background rgba(245,158,11,0.10) · border rgba(245,158,11,0.25) · color #fcd34d
v-surface-danger — Use for error states and irreversible-action warnings: network mismatch, fund loss risks. Background rgba(240,68,56,0.10) · border rgba(240,68,56,0.25) · color #fca5a5
v-surface-muted — Use for neutral control rows: toggle lists, settings rows, form group backgrounds. Background var(--bg-body) · border var(--border) · color var(--text-secondary)

17 · Accessibility Baseline Required for all pages
  • Text contrast ≥ WCAG AA (4.5:1 normal, 3:1 large)
  • Keyboard focus ring visible — box-shadow: 0 0 0 3px var(--focus-ring)
  • Click targets ≥ 36px height (all v-btn variants comply)
  • Icon-only buttons must have aria-label
  • Error messages connected to inputs via aria-describedby
  • Modals must trap focus and dismiss on Escape
  • Respect prefers-reduced-motion — disable non-essential animations
Focus ring token: --focus-ring: rgba(70,95,255,0.48) — applied via :focus-visible on all interactive components.
