# 07 · Admin V3 控制台（私有模块）

## 1. 为什么控制台不随源码发布

Admin V3 是**运营控制台**，具备以下能力，因而不适合公开：

- 全局配置治理（策略参数、费率、积分规则）。
- CMS（菜单 / 横幅 / 首页卡片 / i18n）。
- 积分调账与推荐关系管理。
- 数据库可观测工具。
- **可写入 `.env` 与环境级状态**，可直接移动真实资金。

控制台被设计为**私有、单独授权**的模块：它不包含在本开源发行版中，也不受
本仓库 Apache-2.0 许可覆盖；本仓库不授予对其的任何权利。
