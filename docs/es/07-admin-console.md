# 07 · Consola Admin V3 (Módulo Privado)

## 1. Por qué la consola no se publica

Admin V3 es una **consola de operaciones** con las siguientes capacidades, razón por la
cual no es abierta:

- Gobernanza de configuración global (parámetros de estrategia, tarifas, reglas de puntos).
- CMS (menús / banners / tarjetas de inicio / i18n).
- Ajuste de puntos y gestión de relaciones de referidos.
- Herramientas de observabilidad de base de datos.
- **Puede escribir `.env` y estado a nivel de entorno**, y puede mover fondos reales directamente.

La consola está diseñada como un módulo **privado y licenciado por separado**: no forma
parte de esta distribución open-source, no está cubierta por la licencia Apache-2.0 de
este repositorio, y este repositorio no otorga derechos sobre ella.

## 2. Cómo obtenerla (en orden de preferencia)

1. **Nivel de patrocinio (recomendado)** — patrocine el proyecto en GitHub Sponsors / Polar
   en el nivel *Operator* y será invitado al repositorio privado de admin (mensual) o
   recibirá un enlace de descarga único con licencia escrita. Automatizado, facturado,
   revocable.
2. **Servicio de alojamiento / despliegue gestionado** — para equipos que no quieren
   autoalojarse; la consola está incluida.
3. **Contacto directo** — X/Twitter: [@VeyraTrade](https://x.com/VeyraTrade) (las
   respuestas pueden tardar; prefiera la opción 1).

## 3. Relación con el código open-source

- Sitio de usuario, API, copytrader, motor de estrategia: Apache-2.0 — construya sobre
  ellos, sujeto a la licencia.
- Consola Admin V3: una licencia comercial separada, negociada individualmente.
